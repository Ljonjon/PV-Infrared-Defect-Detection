# Test images

Place the PV infrared test images in this directory. Supported inputs include `.jpg`, `.jpeg`, and `.png`.

The test image package is not redistributed in this Git repository. To request it, email **ljonjon540122@gmail.com** with the subject:

```text
[PV Defect] Request test dataset and inference model
```

Example:

```bash
python detect.py --weights weights/best.pt --source test_images/JPEGImages
```
